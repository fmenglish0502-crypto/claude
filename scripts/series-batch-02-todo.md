# 참교육 시리즈 대본 대기 목록 2 (사용자 요청, 2026-11-25) — 다음 대본 작업 때 batch-01처럼 장면표로 쓰기

공통: 지어낸 인물·회사·장소. 오해 → 분노 → 사이다 → 다음 화 떡밥(완결 없음). AI 실사. 1~4화 게시 + 합본, 5화 보류.
민감 주제(우울증·비만)는 피해자를 웃음거리로 만들지 않는다. 혼나는 건 빌런의 말과 행동.

1. 우울증 직원에게 "주변 사람이 더 고생"이라며 악담하는 빌런 동료
   - 사이다 방향: 회사 인사위원회·직장 내 괴롭힘 신고, 녹음 증거, 빌런이 같은 말을 상사에게 들음. 마지막엔 피해 직원이 회복해 인정받음.
2. 비만이라고 뒷담하는 직원
   - 사이다 방향: 단톡방 뒷담이 실수로 전체방에 전송 / 뒷담 대상이 사내 건강 프로젝트 리더로 발탁 / 외모 비하 징계.
3. 헬스장 민폐 (기구 독점, 땀 안 닦기, 덤벨 안 정리, 거울 앞 영상 촬영)
   - 사이다 방향: 관장 경고 누적 → 회원권 정지, 촬영한 영상에 본인 민폐가 다 찍혀 역바이럴.
4. 아파트 갑질 주민 (경비원·택배기사에게 막말, 주차 갑질)
   - 사이다 방향: 입주민 회의에서 CCTV 공개, 경비원이 알고 보니 퇴직한 전직 고위직 / 주민들이 연대해 사과문 게시.
5. 대형마트에서 보험금 노리고 일부러 넘어지는 보험사기범
   - 사이다 방향: 마트 CCTV 다각도 분석, 같은 수법 반복 이력 조회, 보험사 조사팀·경찰. (보험사기는 처벌 대상)
6. 불효자 (부모 재산만 노리고 연락 끊었다가 돌아온 자식)
   - 사이다 방향: 부모가 재산을 돌봐준 이웃/요양보호사·사회단체에 기부하는 유언장, 녹음된 막말 공개.

더 붙일 수 있는 것: 무단 반려견 배변 방치, 키즈카페 진상 부모, 결혼식 축의금 먹튀 친구.
